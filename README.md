# MINISO × 时代少年团｜代言人IP营销与粉丝经营工作台

面向名创优品品牌营销策划团队的营销工作台，将年度节点规划、项目执行、热点监测、粉丝洞察与品牌权益核对集中在一个页面中，帮助团队把营销机会转化为可执行的项目排期与内容方案。

平台围绕一个日常问题组织信息：**今天整个营销团队最值得关注什么？**

当前版本为可本地运行的交互原型：前端使用 HTML、CSS 和原生 JavaScript，项目等数据通过浏览器 `localStorage` 保存，微博实时热搜由独立 Python 代理提供。适合方案演示、工作流验证与单机使用；尚未接入多人共享数据库、账户权限和正式审批服务。

### 项目排期与进度

项目详情以甘特图为主体，按策划筹备期、执行上线期、复盘收尾期组织任务。时间轴随项目周期生成，点击任务条可编辑任务信息，状态支持「已完成」「进行中」「待启动」。

整体完成进度按已完成阶段数除以阶段总数计算，并同步显示任务总数、已完成数、进行中数与待启动数。该百分比表示执行进度，不代表曝光、销售或其他营销目标达成率。

当前内置案例包括「2026开学季」与「刘耀文生日礼物创意项目」。实际显示以当前版本及本机保存的数据为准。

### 热点监测与创意参考

微博监测获取官方热搜总榜最多50条，用固定关键词库匹配标题，并分为 TNT 热点与 MINISO 热点：

> 时代少年团、马嘉祺、丁程鑫、宋亚轩、刘耀文、张真源、严浩翔、贺峻霖、TNT、时代峰峻、MINISO、名创优品、潮玩

单人或公司话题以「记忆留存」为主；团体与品牌话题根据标题规则判断是否适合生成创意。创意输出保留「蹭热角度」「内容形式建议」「风险提示」「时效建议」，可从产品交易转化、社媒互动与品牌认知等方向展开。

自定义检索可输入其他关键词，在当前榜单中搜索，结果仅展示话题信息，不写入记忆库。主动保存的话题和创意可在记忆库查看、删除或标记已用。

当前营销判断主要采用规则模板，预留了 `window.WEIBO_AI_API` 接口。标题规则不是完整舆情分析，创意建议仍需结合实际内容与项目情况判断。

## 推荐使用流程

1. **看当天重点**：从营销驾驶舱查看待办、近期节点和项目进度。
2. **选择营销节点**：在日历中查看节点详情，生成 Brief 草案或创建项目模板。
3. **落实项目排期**：在项目中心编辑周期与阶段任务，明确负责人、交付物和截止日期。
4. **补充热点与粉丝洞察**：检索相关话题，结合粉丝画像形成创意参考，将有价值的内容保存到记忆库。
5. **核对合作边界**：查阅成员档案、品牌资料与权益矩阵，在风险禁忌中逐项核对。
6. **更新执行状态**：通过甘特图维护任务状态，返回驾驶舱查看同步后的进度与安排。

## 数据与保存方式

工作台优先读取本机浏览器已有数据，没有保存记录时使用页面内置默认数据。

| 数据 | 保存位置 |
| --- | --- |
| 项目及阶段任务 | `localStorage`：`project_data_{项目id}` |
| 部门资料 | `localStorage`：`project_data_departments` |
| 部门分配关系 | `localStorage`：`project_data_department_assignments` |
| 日历节点 | `localStorage`：`miniso-tnt-calendar-v4` |
| 艺人热搜记忆 | `localStorage`：`tnt_memory_list` |
| 蹭热创意收藏 | `localStorage`：`tnt_favorite_list` |
| 实时榜单、自定义检索结果 | 页面运行期间的数据；不作为共享历史数据库 |

本地保存只对当前浏览器和访问来源有效。更换浏览器、电脑、域名或端口，或从本地文件切换到 HTTP 地址，不会自动迁移已有修改；清除网站数据也会影响保存记录。分享 HTML 文件不会带上浏览器中的项目修改和记忆库。

「重置数据」用于恢复默认项目数据，确认后会重置项目及相关部门配置，不应理解为仅重置当前选中的一条任务。记忆库有独立的清空入口。

## 数据口径

粉丝画像中的合成样本用于展示结构与验证流程，不能作为真实粉丝规模、成员占比或消费者偏好的结论。工作台采用以下证据口径：

- **有效样本**：正文非空、发布时间不晚于截止日；同一 `source_ref` 只计一次，缺失互动数不补0。
- **议题占比**：标签内容数 ÷ 有效已采样内容数；允许多标签，合计可超过100%，不代表全体粉丝的偏好概率。
- **偏好代理**：结合标签占比、平台互动率和人工确认；互动数本身不能证明「喜欢」。

微博接口提供的是当前榜单快照。页面的检索日期与接口 `date` 参数不构成历史榜单查询能力；实际获取时间以 `fetched_at` 为准。页面换算后的热度分也不等同于微博原始热度或营销效果预测。

品牌信息、公开排期和成员资料需结合来源及核验状态使用。项目中的素材、肖像、署名、音乐和第三方 IP 仍须按合作权益审核；社群约定不等于官方禁令。无真实投后数据时不报告营销增量，复盘任务排期也不代表已经具备真实投后分析数据。

## 分享与部署

本地 `file://` 地址只在自己的电脑上有效。需要让他人通过链接访问时，可将交付页面及其引用资源部署到静态网站服务，并检查图片等资源能否在另一台设备正常加载。

实时微博监测需要另外部署代理，并将页面的 `window.WEIBO_HOT_API` 配置为访问者可用的服务地址。默认的 `127.0.0.1` 指向访问者自己的电脑，不能直接作为公开网站的后端地址。HTTPS 页面应配套可访问的 HTTPS 代理；当前代理按本地使用设计。

当前部署只共享页面，各访问者的本地数据仍彼此独立。若需要多人共同编辑项目、共享审批状态与记忆库，需进一步接入服务端数据存储和账户权限。

## 维护说明

页面主要逻辑集中在 `index.html`。修改工作版本后，应同步交付目录中的对应文件，并检查项目切换、任务保存后刷新、驾驶舱联动、热点空状态和本地数据恢复等关键流程。

项目未附带开源许可证；品牌标识、人物照片和第三方素材的使用范围，以各自授权为准。
